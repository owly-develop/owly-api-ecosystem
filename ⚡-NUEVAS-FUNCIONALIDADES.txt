┌──────────────────────────────────────────────────────────────────────────────┐
│  🔥 LEADS - 11 ENDPOINTS NUEVOS                                              │
└──────────────────────────────────────────────────────────────────────────────┘

    POST   /api/leads/bulk_assign/              → Asignar múltiples leads
    POST   /api/leads/bulk_status_change/       → Cambiar status masivamente
    GET    /api/leads/{id}/timeline/            → Timeline completo del lead
    POST   /api/leads/{id}/add_note/            → Agregar nota con timestamp
    GET    /api/leads/upcoming_followups/       → Follow-ups próximos (7 días)
    GET    /api/leads/overdue_followups/        → Follow-ups vencidos
    GET    /api/leads/hot_leads/                → Leads calientes (alta prioridad)
    GET    /api/leads/duplicates/               → Detectar duplicados
    GET    /api/leads/performance_by_source/    → Performance por fuente

    ⭐ FILTROS AVANZADOS:
       ?score_min=70&score_max=100
       ?ai_probability_min=80
       ?budget_min=100000&budget_max=500000
       ?created_after=2024-01-01&created_before=2024-12-31
       ?status_in=new,contacted,qualified
       ?priority_in=high,urgent
       ?source_in=website,facebook
       ?has_follow_up=true
       ?requires_attention=true
       ?search=john+doe

┌──────────────────────────────────────────────────────────────────────────────┐
│  💡 EJEMPLOS DE USO                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

    📌 Asignar 10 leads de una vez:
       POST /api/leads/bulk_assign/
       {
         "lead_ids": ["uuid1", "uuid2", ...],
         "user_id": "user_uuid"
       }

    📌 Ver timeline de un lead:
       GET /api/leads/{id}/timeline/

    📌 Buscar leads calientes que necesitan atención:
       GET /api/leads/hot_leads/?requires_attention=true

    📌 Detectar duplicados antes de importar:
       GET /api/leads/duplicates/

    📌 Ver performance por fuente:
       GET /api/leads/performance_by_source/

    📌 Reservar unidad para un lead:
       POST /api/projects/units/{id}/reserve/
       {"lead_id": "lead_uuid"}

    📌 Buscar unidades similares:
       GET /api/projects/units/similar/?bedrooms=2&unit_type=2BR

    📌 Proyectos por ubicación:
       GET /api/projects/by_location/

┌──────────────────────────────────────────────────────────────────────────────┐
│  🚀 CÓMO PROBAR                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

    1. Inicia el servidor (si no está corriendo):
       docker-compose up -d

    2. Accede al admin:
       http://localhost:8000/admin/
       → Verás badges de colores, filtros avanzados, acciones en masa

    3. Prueba los endpoints en Swagger:
       http://localhost:8000/api/docs/
       → Todos los nuevos endpoints están documentados

    4. Prueba un endpoint nuevo:
       curl -X GET "http://localhost:8000/api/leads/hot_leads/" \
         -H "Authorization: Bearer YOUR_TOKEN"
