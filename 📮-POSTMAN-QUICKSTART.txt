│  ⚡ OPCIÓN 1: IMPORTAR JSON (MÁS RÁPIDO)                                     │
└──────────────────────────────────────────────────────────────────────────────┘

    PASO 1: Abrir Postman

    PASO 2: Import → Upload Files
            Selecciona: postman_collection.json

    PASO 3: Se crea colección "OWLY CRM API" automáticamente

    PASO 4: Configurar Environment
            • New Environment → "OWLY Local"
            • Variable: base_url = http://localhost:8000/api
            • Variable: access_token = (vacío por ahora)
            • Save

    PASO 5: Hacer Login
            • Carpeta "🔐 Authentication" → "Login"
            • Send
            • Copiar el "access" del response
            • Pegar en variable "access_token" del environment

    PASO 6: ¡Probar cualquier endpoint!
            • Todos usan {{base_url}} y {{access_token}}
            • Solo hacer click y Send

┌──────────────────────────────────────────────────────────────────────────────┐
│  🚀 PRUEBA RÁPIDA (2 MINUTOS)                                                │
└──────────────────────────────────────────────────────────────────────────────┘

    PASO 1: Health Check (sin auth)

    curl http://localhost:8000/api/health/

    Deberías ver:
    {
      "status": "healthy",
      "database": "connected",
      "cache": "connected"
    }

    PASO 2: Login

    curl --location 'http://localhost:8000/api/auth/login/' \
    --header 'Content-Type: application/json' \
    --data-raw '{
        "email": "admin@owlycrm.com",
        "password": "admin123"
    }'

    COPIA EL ACCESS TOKEN

    PASO 3: Dashboard (reemplaza TU_TOKEN)

    curl --location 'http://localhost:8000/api/analytics/dashboard/' \
    --header 'Authorization: Bearer TU_TOKEN'

    Verás stats con DATOS REALES (300 leads, 12 proyectos, etc.)

    PASO 4: Ver Leads

    curl --location 'http://localhost:8000/api/leads/' \
    --header 'Authorization: Bearer TU_TOKEN'

    Verás los 300 leads creados!

┌──────────────────────────────────────────────────────────────────────────────┐
│  💡 TIPS PARA POSTMAN                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

    TIP 1: Usar Variables
    • En lugar de escribir el token cada vez
    • Crea variable: {{access_token}}
    • Úsala en Authorization header

    TIP 2: Tests Automáticos
    • En tab "Tests" de Login:
      pm.environment.set("access_token", pm.response.json().access);
    • El token se guarda automáticamente!

    TIP 3: Colecciones
    • Organiza endpoints en carpetas
    • Leads, Projects, Analytics, etc.
    • Fácil de navegar

    TIP 4: Guardar IDs
    • Después de crear lead/project:
      pm.environment.set("lead_id", pm.response.json().id);
    • Usar {{lead_id}} en otros requests

    TIP 5: Pre-request Script
    • Auto-login antes de cada request
    • Ver ejemplo en POSTMAN_COLLECTION.md
