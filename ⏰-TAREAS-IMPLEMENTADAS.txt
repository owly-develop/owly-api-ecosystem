│  🔌 EJEMPLO: GESTIONAR DESDE LA API                                          │
└──────────────────────────────────────────────────────────────────────────────┘

    // Listar todas las tareas
    const tasks = await fetch('/api/scheduled-tasks/', {
      headers: {'Authorization': `Bearer ${token}`}
    });

    // Crear tarea
    const newTask = await fetch('/api/scheduled-tasks/', {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        name: 'Mi Tarea',
        description: 'Hace algo útil cada día',
        category: 'notifications',
        task_name: 'apps.myapp.tasks.my_task',
        frequency: 'daily',
        hour: 10,
        minute: 0,
        is_active: true
      })
    });

    // Pausar tarea
    await fetch(`/api/scheduled-tasks/${id}/deactivate/`, {
      method: 'POST',
      headers: {'Authorization': `Bearer ${token}`}
    });

    // Ejecutar ahora
    await fetch(`/api/scheduled-tasks/${id}/run_now/`, {
      method: 'POST',
      headers: {'Authorization': `Bearer ${token}`}
    });


┌──────────────────────────────────────────────────────────────────────────────┐
│  ⏰ PROGRAMACIÓN SIMPLIFICADA                                                │
└──────────────────────────────────────────────────────────────────────────────┘

    El usuario NO TÉCNICO solo selecciona:

    FRECUENCIA:
    • Cada Hora       → Se ejecuta cada hora
    • Diario          → Una vez al día
    • Semanal         → Un día a la semana
    • Quincenal       → Días 1 y 15
    • Mensual         → Un día del mes

    HORA (formato 24h):
    • 0  = 12 AM (medianoche)
    • 8  = 8 AM (mañana)
    • 12 = 12 PM (medio día)
    • 14 = 2 PM (tarde)
    • 18 = 6 PM (fin del día)
    • 20 = 8 PM (noche)

    DÍA (si es semanal):
    • Lunes
    • Martes
    • Miércoles
    • Jueves
    • Viernes
    • Sábado
    • Domingo

    DÍA DEL MES (si es mensual):
    • 1-31

    ✨ El sistema convierte esto automáticamente a Crontab!

┌──────────────────────────────────────────────────────────────────────────────┐
│  📊 COMPARACIÓN: ANTES vs AHORA                                              │
└──────────────────────────────────────────────────────────────────────────────┘

    ANTES (Celery Beat Nativo):
    ❌ Requiere código Python
    ❌ Editar celery.py
    ❌ Conocer sintaxis crontab
    ❌ Redeploy para cambios
    ❌ No intuitivo
    ❌ Solo para devs

    AHORA (ScheduledTask):
    ✅ Interfaz visual simple
    ✅ Crear desde admin
    ✅ No requiere código
    ✅ Cambios inmediatos (no redeploy)
    ✅ Muy intuitivo
    ✅ Para cualquier usuario

    RESULTADO:
    • Manager puede crear reportes sin IT
    • Sales puede configurar recordatorios
    • Finance puede programar alertas
    • Todos autónomos
