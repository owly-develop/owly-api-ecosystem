┌──────────────────────────────────────────────────────────────────────────────┐
│  🔧 FIXTURES DISPONIBLES                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

    Usa estos en tus tests:

    api_client               → API client no autenticado
    company                  → Company de prueba
    another_company          → Otra company (multi-tenant)
    admin_user               → Usuario admin
    manager_user             → Usuario manager
    sales_user               → Usuario sales
    authenticated_client     → Client autenticado como sales
    admin_client            → Client autenticado como admin
    manager_client          → Client autenticado como manager

    FACTORIES (para crear datos de prueba):
    CompanyFactory()         → Crea company con datos random
    UserFactory()            → Crea user con datos random
    ProjectFactory()         → Crea project con datos random
    UnitFactory()            → Crea unit con datos random
    LeadFactory()            → Crea lead con datos random
    QuoteFactory()           → Crea quote con datos random

    EJEMPLO 2: Usar factories para crear datos
    
    def test_with_many_leads(company):
        from tests.factories import LeadFactory
        leads = LeadFactory.create_batch(100, company=company)
        assert Lead.objects.count() == 100

    EJEMPLO 3: Test de multi-tenant
    
    def test_isolation(authenticated_client, another_company):
        # Crear lead en otra company
        lead = Lead.objects.create(
            company=another_company,
            ...
        )
        # Intentar acceder - debe fallar
        url = reverse('lead-detail', kwargs={'pk': lead.id})
        response = authenticated_client.get(url)
        assert response.status_code == 404  # ✅ Isolated!
