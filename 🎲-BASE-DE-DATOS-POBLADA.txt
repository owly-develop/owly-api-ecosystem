┌──────────────────────────────────────────────────────────────────────────────┐
│  🔄 REPOBLAR BASE DE DATOS                                                   │
└──────────────────────────────────────────────────────────────────────────────┘

    SI QUIERES EMPEZAR DE CERO DE NUEVO:

    docker-compose exec web python manage.py seed_data --clear

    SI QUIERES AGREGAR MÁS DATOS:

    docker-compose exec web python manage.py seed_data

    OPCIONES DISPONIBLES:
    --clear              Limpiar antes de poblar
    --companies 5        Crear 5 empresas (default: 3)

    make seed            # Poblar base de datos
