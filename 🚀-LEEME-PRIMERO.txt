┌──────────────────────────────────────────────────────────────────────────────┐
│  ⚡ INICIO RÁPIDO (3 PASOS)                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

    1️⃣  Crea un archivo .env con este contenido:

        SECRET_KEY=django-insecure-local-dev-key
        DEBUG=True
        ALLOWED_HOSTS=localhost,127.0.0.1,0.0.0.0
        DATABASE_URL=postgresql://owly_user:owly_secure_password_2024@db:5432/owly_crm
        REDIS_URL=redis://redis:6379/0
        CELERY_BROKER_URL=redis://redis:6379/0
        CELERY_RESULT_BACKEND=redis://redis:6379/0
        CORS_ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000
        USE_S3=False
        EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend
        JWT_ACCESS_TOKEN_LIFETIME_MINUTES=60
        JWT_REFRESH_TOKEN_LIFETIME_DAYS=7


    2️⃣  Inicia los servicios:

        docker-compose up -d


    3️⃣  Configura la base de datos:

        docker-compose exec web python manage.py migrate
        docker-compose exec web python manage.py createsuperuser

┌──────────────────────────────────────────────────────────────────────────────┐
│  🆘 ¿PROBLEMAS?                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

    Puerto 8000 ocupado?
        → Edita docker-compose.yml y cambia "8000:8000" por "8001:8000"

    Base de datos no conecta?
        → Espera 10 segundos después de "docker-compose up -d"

    Olvidé la contraseña?
        → docker-compose exec web python manage.py changepassword tu@email.com

    Empezar de cero?
        → docker-compose down -v
